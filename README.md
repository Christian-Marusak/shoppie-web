# Shoppie – web

Statický web pre iOS appku Shoppie (úvod, podpora, ochrana súkromia) v slovenčine, češtine a angličtine.
Čisté HTML + `assets/style.css`. Žiadne cookies, analytika ani externé zdroje.

- `index.html` – presmeruje podľa jazyka prehliadača na `sk/`, `cs/` alebo `en/`
- `sk/`, `cs/`, `en/` – `index.html`, `support.html`, `privacy.html`
- `404.html` – odkazy počítajú s repozitárom `shoppie` (pozri komentár v súbore)
